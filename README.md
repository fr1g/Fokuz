# Fokuz — 图片区域高亮

给图片画一个选区，高亮其中一块区域，其余内容用遮挡 / 模糊 / 马赛克隐藏，选区内还可以放大镜放大，最后导出一张与原图**分辨率一致**的图片。

纯前端 SPA + PWA，所有处理均在浏览器本地完成，图片不会上传。

## 使用

```bash
npm install
npm run dev      # 开发
npm run build    # 构建产物 + Service Worker（dist/）
npm run preview  # 本地预览构建产物
```

## 功能

- **选区**：矩形 / 圆角矩形（圆角比例可调）/ 椭圆，单选区
  - 按住 **Shift** 拖拽 → 正方形 / 正圆；调整大小时按住 Shift 锁定宽高比
  - 选区可直接拖动，边框 8 个手柄拖拽调整大小
  - 按下鼠标拖拽期间显示辅助线：椭圆为横纵直径十字、矩形为中心宽高线，并标注原图像素尺寸
- **选区外效果**：黑色 / 白色半透明遮挡（不透明度可调）；模糊或马赛克（强度可调，二者选一）
- **选区描边**：预设色板 + 自定义颜色、宽度可调
- **放大镜**：选区内内容以选区中心放大 1–4 倍（倍数可调）
- **撤销 / 重做**：`Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z` 或 `Ctrl/Cmd+Y`；`Delete` / `Backspace` / `Esc` 删除选区
- **画布**：滚轮缩放（桌面）、双指捏合缩放 + 双指拖动平移（触屏）、空格 / 中键平移、双击空白处或点"适应"复位
- **图片加载**：点击选择、拖拽到页面、`Ctrl+V` 粘贴；自动处理 EXIF 方向；支持 PNG / JPG / WebP / TIFF / HEIC（HEIC 经 libheif wasm 解码，按需加载）
- **导出**：三个选项 —— 【原格式(源格式)】【JPEG】【WebP】
  - **原格式**：保持源图格式并按其原有压缩规格导出（JPEG 会从文件的量化表反推原图质量，不出质量滑条；PNG 无损；TIFF 展平为无压缩单页并告知图层不保留；HEIC 等浏览器无法编码的格式此选项置灰）
  - **JPEG / WebP**：可调压缩质量（滑条初始值为检测到的原图质量，方便"进一步压缩"），并预估文件大小
  - 分辨率恒与原图一致；WebP 编码不受支持时自动回退 PNG

## 技术栈

Vite · React 19 · TypeScript · Tailwind CSS v4 · tdesign-icons-react · vite-plugin-pwa（可安装、离线可用）

预览与导出共用同一条 Canvas 渲染管线（`src/lib/render.ts`），保证所见即所得；模糊 / 马赛克层按 (图片, 模式, 强度) 缓存，拖动选区不重算。
